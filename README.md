# Office Attendance Calculator:-

A Python-based web application built with Streamlit to automate office attendance calculations from biometric Excel reports. Upload monthly attendance sheets and instantly generate detailed working hours reports for all employees.

## Features

- Upload attendance sheets in .xls or .xlsx format
- Automatic employee detection and data extraction
- Calculate working hours with lunch break detection
- Three comprehensive report views:
  - Summary Dashboard
  - Day-wise Details
  - Individual Employee Report
- Search and filter employees
- Download reports in CSV or Excel format
- Clean and professional user interface

## Technology Stack

- Python 3.11
- Streamlit
- Pandas
- OpenPyXL (for .xlsx files)
- xlrd (for .xls files)

## Installation

### Prerequisites

- Python 3.9 or higher
- pip package manager
